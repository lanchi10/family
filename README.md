# 🏥 דשבורד קליני: IRIScan Visualizer 7 בריפוי בעיסוק (OT Dashboard)

דשבורד אינטראקטיבי, ויזואלי ומורחב בעברית המיועד למרפאות בעיסוק (Occupational Therapists). הדשבורד מסביר, מציג ומדגים את יתרונות ואפשרויות השימוש הטיפולי במכשיר **IRIScan Visualizer 7 Dyslexia** (מצלמת מסמכים וסורק 4K 13MP עם תוכנת Readiris DYS OCR & TTS) בטיפול בילדים על הרצף האוטיסטי (ASD), ילדים עם קשיים בוויסות התחושתי, קשיי למידה ותפקודים ניהוליים.

---

## ✨ תכונות מרכזיות בדשבורד

- **🎥 סימולטור קליני אינטראקטיבי בלייב:**
  - 4 מצבי עבודה טיפוליים (מיקוד קשבי והקראה, מוטוריקה עדינה ותכנון תנועה במסך מפוצל, ויסות תחושתי ותאורה מבוקרת, משטחי A3 וסמלי תקשורת תמ"ח).
  - פילטרים חזותיים בלייב: ניגודיות גבוהה "צהוב על שחור" (להפחתת סינוור ועומס), ירוק מרגיע ושחור-לבן.
  - הקראה קולית (TTS בעברית) עם הדגשת מילים בזמן אמת וסרגל מיקוד חזותי דיגיטלי.
  - שליטה בעוצמת תאורת LED ניטרלית (Flicker-Free) וזום 4K.

- **🧩 6 תחומי טיפול מרכזיים:**
  1. תפקודים ניהוליים ומיקוד קשבי
  2. ויסות תחושתי חזותי ומגע
  3. תכנון תנועה ומוטוריקה עדינה
  4. תקשורת תומכת וחלופית (תמ"ח)
  5. הנגשת דיסלקציה וטקסט (Readiris DYS OCR & TTS)
  6. שילוב בכיתה ולמידה מרחוק

- **🎯 מטריצת מטרות IEP (תוכנית שילוב אישית):**
  - טבלה מפורטת עם כפתורי סינון דינמיים המקשרת בין מטרות IEP, תכונות המכשיר, אופן היישום בקליניקה ומדדי הצלחה.

- **🛠️ מחולל מערכי טיפול אישי (Interactive OT Session Planner):**
  - הפקת מערך טיפול מובנה ל-45 דקות בהתאם לגיל הילד, אתגר מרכזי ורמת תפקוד ברצף האוטיסטי.

- **📖 תיאורי מקרה קליניים ומפרט טכני-קליני מותאם.**

- **🖨️ תמיכה מלאה בהדפסה (Print-Ready):**
  - ייצוא והדפסת תמציות קליניות ומערכי טיפול בלחיצת כפתור.

## 🚀 הרצה מקומית

1. שכפל את המאגר:
   ```bash
   git clone <REPOSITORY_URL>
   cd ot-visualizer-dashboard
   ```

2. הפעל שרת מקומי (למשל באמצעות `npx http-server` או פתיחת `index.html` בדפדפן):
   ```bash
   npx http-server . -p 8080
   ```

3. פתח את הדפדפן בכתובת:
   `http://localhost:8080`
